# 대상 실행 파이프라인

> 구축 과정이 생산·관리하는 대상 산출물이다. 구축 단계와 현재 작업 상태는 구축 맥락 기록을 참조한다.
> 기존 실행 파이프라인 정본이 있으면 이 템플릿으로 복제하지 않는다.

## 목표와 경계

| 항목 | 값·참조 |
|---|---|
| 사용자 목표 | <누구의 어떤 입력을 어떤 결과로 만드는가> |
| 입력·출력 계약 | <정본 참조> |
| 필수 제약·성공 조건 | <정본 참조> |
| 현재 기준선 | <정본 위치 + revision, 초안이면 초안 명시> |
| 구축 맥락 | <단계 소유권·현재 진척·수정 권한 참조> |
| 실제 도구·환경 | <제공된 도구·버전·준비 상태; 없으면 필요 capability> |

## 실행 단계

| 실행 ID·책임 | 입력·생산자 | 출력·소비자 | 선행·분기·병렬·반복 | 완료·실패 처리 | 지시문·구현 정본 | 실제 도구 |
|---|---|---|---|---|---|---|
| <ID·책임> | <계약·필드 참조> | <계약·필드 참조> | <조건·횟수·합류> | <판정·복구·종료> | <경로#앵커> | <제공된 기능 또는 미연결> |

## 검증 연결

- 설계 검사: <책임·계약·입력 누락·완료·실패 경로 등 기준 참조>
- 실행 검사: <실제 실행할 테스트와 필요한 도구·환경>
- 개선 사례: <실패 분석·후보 작성용>
- 검증 사례: <비교 채택용>
- 필수 회귀·경계 사례: <보호할 조건>
- 비교 정책: <동일 환경·반복 횟수·지표·회귀 허용치>
- 데이터·부작용 통제: <fixture·mock·replay·sandbox·실행 권한>
- 미정·미구현: <해당 항목·담당 구축 단계·다음 작업>

새 파이프라인은 현재 구축 단계에서 필요한 부분만 작성하고 나머지의 상태를 명시한다. 설계 완료·구현 완료·실행 검증 완료를 별도로 관리한다.
