# Recursive Control Reference Pack

Use these optional ledgers when the baseline includes recursive horizontal/vertical execution or maintenance lifecycle control.

| File | Purpose |
|---|---|
| `10_ELEMENT_REGISTRY.jsonl` | Stable independent system element identity |
| `11_TOPIC_REGISTRY.jsonl` | Stable work-topic identity and lifecycle |
| `12_CONTEXT_INDEX.md` | Context IDs, versions, orientation, topic, status, hash |
| `13_RESPONSIBILITY_LEDGER.md` | Element, relationship, contract ownership and mutation authority |
| `14_METHOD_CAPABILITY_MAP.md` | Method requirements and concrete tool binding coverage |
| `15_MAINTENANCE_CASE_INDEX.md` | Case state, topic, parent-child relation, closure |
| `16_CONTEXT_PATCH_REGISTER.md` | Proposed, accepted, rejected, superseded context changes |

These are audit and routing aids. Current normative rules remain in the canonical baseline and published context snapshots.
