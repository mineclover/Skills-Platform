# Routing Signals

Signals are evidence, not automatic triggers.

| Source signal | Likely core owner | Possible overlay |
|---|---|---|
| User story, use case, business rule | Product | UI editor, knowledge publishing |
| Module/component/service, adapter, boundary | Architecture | Browser DevTools, AI agent |
| Schema/entity/ID/state/migration | Data/state | Knowledge publishing, 3D |
| Endpoint/event/message/file format | Interfaces | Browser DevTools, AI agent |
| Pipeline/sequence/retry/cancel/rollback | Runtime | AI agent, 3D, Browser DevTools |
| SLO/authz/logging/deploy/backup | Quality/operations | Any overlay |
| Test/acceptance/evidence/release gate | Testing/acceptance | Any overlay |
| Milestone/TODO/dependency/blocker | Delivery roadmap | Any overlay |
| Canvas/DOM/selection/snap/coordinate | Architecture, data, runtime | UI editor |
| DevTools/workspace/override/content script | Architecture, interfaces, runtime | Browser DevTools |
| Agent/tool/prompt/context/eval | Architecture, interfaces, runtime, quality | AI agent |
| Rig/bone/mesh/retarget/render | Data, runtime, testing | 3D/motion |
| JSON-LD/RDF/taxonomy/publish/provenance | Data, interfaces, runtime | Knowledge publishing |
