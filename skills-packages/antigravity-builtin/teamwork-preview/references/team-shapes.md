# Swarm Team Topologies & Routing

Internal execution paths selected by `teamwork_preview`.

| Topology | Target Workload | Agent Composition |
| :--- | :--- | :--- |
| **Full Team** | Large multi-part features, monorepo refactors, full systems | Orchestrator + Explorers + Milestone Workers + 5-Agent Review Panel |
| **Small Focused Team** | Single bugfix, localized module patch | 1 Implementer + Repeated Adversarial Reviewers |
| **Document Review** | Architectural review, paper analysis | Document Analyst + Security Auditor + Synthesis Agent |
| **Proof Pipeline** | Formal verification, logic proofs | Prover + Step Validator + Counterexample Searcher |
| **Very Large Team** | Extreme parallel search | 100+ Concurrent Agent Swarm Nodes |
