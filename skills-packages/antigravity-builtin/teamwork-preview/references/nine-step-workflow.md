# 9-Step Interactive Prompt Crafting Guide

Step-by-step procedure for preparing high-precision teamwork prompts.

## Steps Overview
1. **Step 1: Elicit the Idea** (Capture 1-2 sentence core purpose and audience).
2. **Step 2: Identify Ambiguity & Team Scale** (Resolve scope dimensions; choose small focused vs full team vs very large team).
3. **Step 3: Determine Integrity Mode** (`development` default, `demo` for rapid prototyping, `benchmark` for strict isolation).
4. **Step 4: Draft Requirements** (2-5 blocks of R1, R2... specifying *what*, not *how*).
5. **Step 5: Design Objective Verification** (Programmatic test suites, reference benchmarks, or agent-as-judge rubrics).
6. **Step 6: Set Acceptance Criteria** (Convert verification into concrete `[ ]` checkable items).
7. **Step 7: Infrastructure Constraints** (Controlled API access for network, cloud storage, or remote jobs).
8. **Step 8: Choose Working Directory** (Explicit top-level working directory directive).
9. **Step 9: Assemble, Validate & Present** (Validate against anti-patterns and present `prompt_draft.md` for user approval).
