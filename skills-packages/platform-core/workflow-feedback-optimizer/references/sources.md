# 근거와 독자 설계 범위

확인일: 2026-09-13. 문서의 `latest`와 저장소의 `main`은 변경될 수 있다. 이 패키지는 TextGrad의 공식 배포물이 아니고, 원본 코드를 포함하거나 Python 패키지에 의존하지 않는다.

## 확인한 1차 자료

| 자료 | 확인한 내용 | 적용 |
|---|---|---|
| [TextGrad 공식 문서](https://textgrad.readthedocs.io/en/latest/index.html) | 자연어 피드백 기반 최적화, 답변 변수와 시스템 프롬프트 최적화 예제 | 수정 대상을 명시하고 피드백으로 후보 텍스트를 갱신한다는 원리 |
| [TextGrad Variable 문서](https://textgrad.readthedocs.io/en/latest/modules/textgrad.variable.html) | 역할 설명, 선행 변수, 계산 그래프의 backward | 결과 의존 관계와 수정 대상의 역할을 고려해 피드백을 연결한다는 원리 |
| [Agent Skills 명세](https://agentskills.io/specification) | `SKILL.md`, name·description, 선택적 참조·스크립트·템플릿, 점진적 로딩 | 짧은 진입 문서와 역할별 세부 참조 구조 |

[TextGrad 공식 저장소](https://github.com/zou-group/textgrad)는 원본 구현을 검토할 때의 출발점이다. 이 업데이트의 구축 절차 인식 계약은 저장소에 존재하는 기능을 추출했다고 주장하지 않는다.

## 이 패키지에서 정의한 정책

구축 절차와 실행 파이프라인의 분리, I0~I7 필수 인식 관문, 정본 소유권·실행 단계 매핑, 현재 위치·호출·인계 계약, 재작업 라우팅, 최신성·중복 호출 검사, 설계 검토와 실행 성능 채택의 분리, 권한·부작용·평가 데이터 통제는 이 사용 목적을 위해 독자적으로 정의한 운영 규칙이다.

TextGrad의 자동 역전파를 그대로 실행하는 구현이 아니다. Agent Skills 표준이 위 도메인 계약을 요구하는 것도 아니다. ‘필수’는 이 스킬 내부의 절차 계약을 뜻한다.

## 실행·검증 범위

Markdown 지침만으로 호스트에서 필수 절차를 기술적으로 강제할 수 있다고 전제하지 않는다. 엄격한 강제가 필요하면 호스트가 맥락·작업·권한·검증 조건을 검사하고 진입·반영·상태 전이를 제어해야 한다.

제공한 Python 스크립트는 이 패키지의 정적 구조만 검사한다. 실제 스킬 행동, 호스트 설치·자동 호출, 실행 파이프라인 성능은 별도 검증 대상이다. 행동 검증 사례와 실제 수행 기록을 구분해 제공한다.
