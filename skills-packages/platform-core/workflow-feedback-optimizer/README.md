# Workflow Feedback Optimizer

프로젝트의 **구축 과정을 먼저 인식한 뒤 그 과정 안에서 파이프라인을 설계·검토·개선하는 에이전트 스킬**이다. TextGrad의 자연어 피드백 원리를 참고한 독자 작성 지침이며 모델 가중치를 학습하지 않는다.

## 진입

[SKILL.md](SKILL.md)가 에이전트의 진입점이다. 필수 0단계에서 구축 절차·현재 위치·산출물·수정 경계·검증·복귀 경로를 인식한다. 이어 이번 호출이 요구한 범위의 작업을 수행하고 구축 절차로 결과를 돌려준다.

```text
구축 절차와 현재 작업을 인식
→ 현재 단계의 목표·산출물·변경·검증·인계를 연결
→ 설계·검토 또는 실행 증거 기반 개선
→ 해당 정본의 소유 단계로 변경·재작업을 연결
→ 검증 범위와 다음 행동을 포함해 반환
```

스킬의 인식 절차는 필수다. 실제 구축 단계 이름·개수·순서는 프로젝트가 소유한다. 사용자 온보딩 설명은 별개이며 재개 때 전체 설명을 반복하지 않는다.

## 실제 워크플로우에 넣는 순서

먼저 구축 절차 정본과 현재 작업 상태, 실행 파이프라인 산출물의 위치를 스킬에 제공한다. 스킬은 이를 실제로 읽어 인식 결과를 만들고, 이번 작업의 현재 단계·허용 변경·완료 기준·반환 위치를 확정한다.

호출자는 프로젝트가 사용하는 단계에 이 스킬을 배치하고 작업 요청·결과의 의미를 연결한다. 자동 호출을 등록할 실제 오케스트레이터나 도구가 없다면 `proposed` 통합 설계까지만 제공한다. 문서에 호출 조건을 적었다고 `connected`로 표시하지 않는다.

예시 요청:

```text
workflow-feedback-optimizer를 현재 구축 작업에 적용해.
구축 절차 정본과 작업 상태를 먼저 읽고,
현재 단계의 목적·입력·산출물·수정 경계·완료 조건·반환 경로를 인식해.
이미 확인된 자료를 다시 질문하지 말고 참조로 연결해.
이번 요청 범위의 작업만 수행한 뒤 검증 범위와 다음 담당 작업을 반환해.
```

## 제공 범위

스킬 지침, 의미 계약, 작성 템플릿, 가상 예제, 행동 수용 사례, 로컬 정적 검사기를 제공한다. 실행 엔진, MCP 서버, 모델 호출 코드, 호스트 전이 제어기·설치기·강제 관문 구현은 포함하지 않는다.

이 폴더를 Agent Skills를 읽는 환경에 제공할 수 있다. 특정 플랫폼의 설치·활성화·도구 권한은 별도 설정이며 이 ZIP이 자동 설치하지 않는다. Python TextGrad는 필요하지 않다. 정적 검사기를 실행할 때만 Python 3.10 이상을 사용한다.

```bash
python3 scripts/validate-package.py
```

실제 검사 범위·결과는 검증 기록에 명시한다. 행동 테스트의 사례 수를 통과 테스트 수로 바꾸어 보고하지 않는다. 현재 정본만 유지하고 레거시 비교본은 패키지에 포함하지 않는다.
