## 📦 Bundle Overview

Low-level agentic design patterns. Turning old engineering wisdom into reflexes your agent reaches for on its own—on any agent.

### 1. re0 Iteration Lifecycle (9 skills)
- `re0`: Master entrypoint and core iteration convention
- `re0-plan`: Seed casebook (`DESIGN.local.md`, `WORKFLOW.local.md`) before turns
- `re0-loop`: 5-turn execution state machine (FRAME ➔ SHAPE ➔ BUILD ➔ PROVE ➔ RETRO)
- `re0-work`: Single-responsibility implementation unit
- `re0-memo`: Cumulative retro and knowledge recording
- `re0-git`: Git commit boundary and hygiene manager
- `re0-merge`: Sequential artifact merger
- `re0-release`: Archive, bump, and finalize release
- `re0-upgrade`: Corpus-wide spec and skill version upgrader

### 2. Critical Thinking & Cognition Reflexes (10 skills)
- `feynman`: Press choices with Feynman explanation tests
- `macrothink`: Step back to high-level architecture when stuck in local traps
- `hate`: Adversarial failure-mode scrutiny
- `mandela`: Audit false memory and hallucinated APIs
- `factchk`: Ground assumptions against concrete code/docs
- `aim`: Recalibrate primary outcome before coding
- `readchk`: Self-diagnose spec/code reading comprehension
- `modelchk`: Verify model context and reasoning tier
- `shower`: Reset assumptions and take a clean-slate view
- `sip`: Decompose massive information into digestible sips

### 3. Code & Context Condensation (4 skills)
- `debloat`: Eliminate dead code, boilerplate, and verbose comments
- `detool`: Replace over-engineered tools with simple file ops
- `dedash`: Prune redundant CLI flags and syntax bloat
- `autobahn`: Fast-track trivial deterministic fixes

### 4. Queue & Architecture Coordination (5 skills)
- `ssotize`: Unify fragmented configurations into a single source of truth
- `prism`: Multi-perspective analysis (security, performance, dx)
- `nba`: Next Best Action calculator
- `catchup`: Rapid session context catch-up
- `reorder`: Dependency-ordered task queue rearrangement
